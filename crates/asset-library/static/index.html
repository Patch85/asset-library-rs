      Search syntax

      goblin archerwords in name, folder, notes or tags (prefix match)
      "fire giant"exact phrase
      -skeletonexclude a word
      tag:undead -tag:bossrequire / exclude a tag
      type:tokenasset type
      is:fav is:untagged is:transparent is:missingflags
      w>=512 h<300pixel dimensions
      color:pink -color:blackdominant colours
      size:large -view:portrait pack:"forgotten adventures"property values
      grid>=70number properties
      has:size -has:sizeproperty set / not set
      ~"lizard humanoid with a spear"describe the image in plain words (AI)
      similar:123looks like asset 123 — or use Find similar (AI)

      Tip: describe an unusual creature with ~"...", select the hits, and tag them all at once.

      Settings

      Runs a local CLIP model. The first time, it downloads about 600 MB. Nothing about your images leaves this computer.

      Import

      Bring in a library made by the Python version of this app: pick its folder (or its data folder). Only works while this library has no folders.

      Properties

      Properties have one value per asset, for how it's made or used (a token's view or size, a map's grid). Tags stay for what's in it.
